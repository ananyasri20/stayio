Stayio is a property rental and listing web application built using the MERN stack. It allows users to browse, search, and manage rental properties with a simple and intuitive interface.
🚀 Features

🏡 Add, update, and delete property listings

📷 Image upload for properties

💰 Display property price, title, and description

🔍 Search and filter functionality

👤 User authentication and authorization

📱 Responsive design
🛠️ Tech Stack

Frontend: HTML, CSS, Bootstrap / Tailwind, EJS

Backend: Node.js, Express.js

Database: MongoDB
